# Upload temporário da baseline 14.22

Este diretório existe somente para concluir a importação dos assets binários/fixtures históricos da versão 14.22.

Envie aqui, **na branch `chore/import-14.22`**, o arquivo original com o nome exato:

```
RV_Cutter_CAD_14_22_CODIGO_FONTE.zip
```

O workflow `Import uploaded 14.22 archive` validará e extrairá o pacote, importará os assets necessários e removerá este diretório de staging automaticamente.

Não altere o conteúdo do ZIP antes do upload.
